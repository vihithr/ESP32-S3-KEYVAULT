========================================================================
    KEYVAULT-ESP32 硬件密码保险箱 - 固件一键烧录包使用说明
========================================================================

欢迎使用 KEYVAULT-ESP32 硬件密码保险箱！
本压缩包已经整合了全部所需固件和烧录工具，解压后即可直接使用，无需单独下载
任何其他文件，也无需调整目录结构。

------------------------------------------------------------------------
【推荐：开箱即用图形化烧录】（适合所有用户，无需 Python）
------------------------------------------------------------------------
1. 使用 Type-C 数据线将 ESP32-S3 开发板连接到电脑 USB 口。
2. 双击打开本目录下的【KEYVAULT-Flasher.exe】。
3. 烧录器会自动扫描并选中您的开发板串口（如 COM3、COM5）：
   - 点击【⚡ 一键烧录固件】按钮。
   - 等待进度跑完并提示“🎉 固件烧录成功”即可！
4. 烧录完成后，开发板将自动重启：
   - 电脑会自动识别出一个新的 USB 虚拟网卡（RNDIS）。
   - 打开浏览器访问 http://192.168.7.1 即可进入硬件保险箱管理界面！

------------------------------------------------------------------------
【备用：脚本方式烧录】（适合已有 Python / Conda 环境的用户）
------------------------------------------------------------------------
- 双击【flash_gui.bat】：以 Python 源码模式启动图形界面。
- 双击【flash.bat】：命令行交互式极简烧录。

------------------------------------------------------------------------
【常见问题排查】
------------------------------------------------------------------------
Q1: 烧录工具提示“找不到串口”或“连接超时 (Connecting...)”？
A1: 请按住开发板上的【BOOT】键不放，轻按一下【RST】(复位)键，然后松开 BOOT 键，
    此时开发板将强制进入 Bootloader 下载模式，在烧录工具中点击【刷新串口】重新烧录即可。

Q2: 烧录完成后浏览器无法打开 http://192.168.7.1？
A2: 请确认将 USB 线连接到了开发板的 USB (OTG) 口（若开发板有两个 Type-C 口，
    烧录可使用 UART/USB 口，运行保险箱网页需连接原生 USB 口）。
    开机后等待 3 秒即可自动分配 IP 地址。

【文件目录结构说明】
------------------------------------------------------------------------
KEYVAULT-ESP32-v1.1.0-Flasher/
├── KEYVAULT-Flasher.exe      # 单文件 GUI 烧录器（双击直接运行）
├── flash_gui.bat             # 备用图形启动脚本
├── flash.bat                 # 备用命令行极简烧录
├── 使用说明.txt              # 本说明文件
├── requirements.txt          # Python 依赖项清单（仅源码运行时需要）
└── firmware/                 # 预编译全量固件目录（已配齐，请勿移动）
    ├── bootloader.bin        # Bootloader 引导分区 (0x0)
    ├── partitions.bin        # 分区表配置 (0x8000)
    └── firmware.bin          # 核心系统固件 (0x10000)
